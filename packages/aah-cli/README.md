# AI Accounts Hub CLI

Standalone `aah` command for AI Accounts Hub.

```bash
npm install -g @murongg/aah-cli
aah list
aah current
```

The npm package has its own standalone CLI version and downloads the matching prebuilt native binary from the `cli-vX.Y.Z` GitHub Release during installation. It stores and reads managed account data from `~/.ai-accounts-hub`.
